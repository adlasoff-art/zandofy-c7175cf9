Commander et suivre sur Zandofy

Parcours mobile (application / PWA) — du panier au paiement Mobile Money, puis suivi de commande. Compte client déjà créé. Texte pédagogique hors captures.

A. Passer commande & payer

1 Panier

Après avoir ajouté un article, ouvrez le Panier (icône en bas de l’écran). Vérifiez la quantité, la couleur / taille, puis le sous-total.

  • Cochez les articles à commander.
  • Les frais de transport exacts se calculent à l’étape suivante.
  • Appuyez sur Commander.

Astuce : sur mobile, le panier s’ouvre en plein écran pour une lecture claire.

2 Adresse & expédition

Choisissez une adresse enregistrée ou saisissez vos informations. Sélectionnez ensuite le mode d’expédition / le transitaire proposé, puis le mode de retrait (souvent retrait au hub avec paiement à l’arrivée).

  • Barre de progression : Adresse → Paiement → Confirmation.
  • Bouton Continuer fixé en bas de l’écran.
  • Retour possible via la flèche en haut.

3 Paiement Mobile Money

Le moyen par défaut est Mobile Money (Orange Money, M-Pesa, Airtel Money, AfriMoney). Les autres moyens (carte, PayPal, hors plateforme…) sont derrière « Voir N alternative(s) ».

  • Choisissez l’opérateur.
  • Saisissez le numéro (indicatif pays, ex. 243…).
  • Acceptez les CGV, puis appuyez sur Payer.

Une demande de paiement apparaît sur le téléphone : validez avec votre code PIN Mobile Money.

4 Confirmation

Une fois le paiement validé, l’écran de confirmation affiche le numéro de commande. Conservez-le pour le suivi. Un e-mail / notification peut aussi confirmer la prise en compte.

  • Vous pouvez retourner à l’accueil ou ouvrir le suivi.
  • La commande apparaît aussi dans Mon compte → Commandes.

B. Suivre la commande

Deux entrées : page Suivi (icône colis / Tracking) avec le numéro de commande, ou détail de commande dans le tableau de bord client.

5 Statuts de suivi (international)

Enchaînement typique après paiement réussi :

  • Reçue — commande enregistrée
  • Confirmée — prise en charge vendeur
  • En préparation — packing
  • En expédition — départ / fret
  • Arrivée au hub — disponible en agence
  • Assignation / Livreur — si livraison last-mile
  • En livraison puis Livrée

Si vous avez choisi le retrait hub : à l’arrivée, présentez-vous à l’agence (paiement à l’arrivée éventuel selon votre choix au checkout).

6 En cas de question

  • Centre d’aide / support dans l’app.
  • Messages vendeur (si conversation ouverte).
  • Gardez le numéro de commande et la référence de paiement Mobile Money.

Après une mise à jour de l’application : si une bannière « Nouvelle version » apparaît, touchez Mettre à jour pour profiter du parcours le plus fluide.
